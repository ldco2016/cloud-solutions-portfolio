# Cloud Solutions Portfolio

This is a collection of cloud architecture designs I created while studying for AWS certifications and working through real-world network and security scenarios.

Each example includes:
- A whiteboard diagram or visual layout
- A short explanation of the use case and goals
- Key AWS services and design choices
- Security and cost considerations

## Use Cases Included
- Secure 3-tier web application (EC2, RDS, ALB, IAM)
- Scalable file storage with S3 and CloudFront
- Basic serverless architecture (API Gateway, Lambda, DynamoDB)

## Why I Built This
I created this portfolio to demonstrate how I approach cloud infrastructure design — with a focus on practicality, security, and AWS best practices.
